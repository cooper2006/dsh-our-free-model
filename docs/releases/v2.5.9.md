# Our Free Model 2.5.9

## 插件更新

本版本发布 DSH 插件，包含自 2.5.8 后已合入主线的修正与新功能：

- **headroom 模型级压缩**：新增 headroom 压缩作为降级链首选，RTK 作为兜底。支持 CCR 增量检索、代理自动启动与加入、fail-open 降级。
- **FleetRelay 线上模型网关**：接入 FleetRelay T1 网关（deepseek-v4.1-flash-free、gpt-6-astra），作为聚合 Provider 的生产备选网关。
- **自动探测禁用**：旧出口判定失效并隔离迟到结果，修复 egress 变更时的缓存污染问题。换出口恢复被旧地区判定隐藏的模型，历史测量保留且重启后仍失效。
- **更新失败重试**（继承 2.5.8）：Windows 备份目录重命名遇到临时占用时重试；再次更新可复用已校验的暂存文件。
- **undici 安全升级**：8.11.2 → 8.12.3，修复 3 个已知漏洞（DoS、SRI bypass、content-encodings）。
- **独立端前端重建**：同步停用自动探测后的前端资源，更新 channels 产物哈希。

独立服务和桌面壳版本保持不变，本次不发布新的 Windows 桌面安装包。标签触发的 macOS 社区构建由现有 CI 单独处理。

## 安装

插件包为 `dsh-our-free-model-2.5.9.tgz`。托管安装请更新 profile 中的可信 tarball 路径，再由宿主重新解析依赖；自行安装按现有插件更新流程操作。

## 验证边界

headroom 压缩、FleetRelay 网关、自动探测禁用、undici 升级使用本地替身验证。未验证真实上游账号调用或生产网关配额限制；测试结果不代表上游客户端、地区或配额限制已解除。

## 回退

回退到 `2.5.8` 的可信插件 tarball，并按宿主安装流程重新解析。保留用户配置、账号及统计数据。
